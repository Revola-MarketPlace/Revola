# API Controllers

Route controllers:
- `authController.js`: Authentication, Google OAuth, profile, avatar
- `productController.js`: Catalog listings, seller CRUD, map locations
- `cartController.js`: Cart add/remove/update per user
- `orderController.js`: Checkout, delivery fee estimation, order tracking
- `paymentController.js`: Chapa initialization, webhook, verification
- `notificationController.js`: User notifications and mark-read
